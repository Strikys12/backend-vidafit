
# VidaFit Backend

VidaFit es una plataforma de comercio electrónico enfocada en el sector fitness y el bienestar, desarrollada como proyecto académico dentro del programa de formación para desarrolladores Junior Full Stack de Generation Colombia.

Este repositorio contiene el desarrollo del **Backend de VidaFit**, construido con **Java y Spring Boot**, encargado de gestionar la lógica de negocio, la interacción con la base de datos y los servicios necesarios para el funcionamiento de la plataforma.

Para la gestión y persistencia de los datos se utiliza **PostgreSQL** como sistema gestor de base de datos.



## Funcionalidades Principales

 - Gestion de Usuarios
 - Gestion de productos
 - Gestion de categorisa
 - Gestion de direcciones
 - Gestion de pedidos
 - Gestion de detalles de pedidos

## Tecnologias utilizadas

 - Java
 - Spring Boot
 - Spring Data JPA
 - PostgreSQL
 - Hibernate
 - Lombok
 - Git & GitHub
